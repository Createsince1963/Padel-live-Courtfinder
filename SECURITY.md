# Security Policy

## Supported Versions

Padel Live Court Finder is currently in beta development.

| Version | Supported |
|---------|-----------|
| 2.2.1x Beta | Yes |
| Older versions | No |

Only the latest published release receives security updates.

## Reporting a Security Vulnerability

Please report security vulnerabilities privately. Do not publish security vulnerabilities as public GitHub issues.

Use one of the following reporting methods:

1. GitHub Private Vulnerability Reporting, if enabled for this repository.
2. Contact the project owner directly through the contact information provided in the repository.

Include the following information where possible:

- A clear description of the vulnerability
- Affected application version
- Android version and device model
- Steps required to reproduce the issue
- Screenshots, logs or error messages
- Possible impact
- Suggested solution, if available

Do not include passwords, API keys, access tokens, personal data or other sensitive information in screenshots or logs.

## Response Process

After receiving a valid security report:

1. The report will be reviewed.
2. The vulnerability will be reproduced where possible.
3. The severity and potential impact will be assessed.
4. A correction will be prepared and tested.
5. A security update will be published when required.

Response times may vary because the application is currently an independently developed beta project.

## Scope

Security reports may include:

- Exposure of secrets or API credentials
- Unauthorized access to application data
- Insecure network communication
- Location data exposure
- Improper Android permission handling
- Unsafe external links or redirects
- Manipulation of court or provider information
- Dependency vulnerabilities
- Authentication or authorization issues
- Installation or update security issues

## Out of Scope

The following are normally outside the project scope:

- Vulnerabilities in third-party booking
