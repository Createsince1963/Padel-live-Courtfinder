# Smart Court Finder

Find. Compare. Play.

Smart Court Finder is an Android application that helps padel and tennis players quickly discover nearby courts, compare availability and prices, and navigate directly to the preferred booking platform.

## Vision

Provide a simple, fast and provider-independent way to find the best available court based on:

- Distance
- Availability
- Price
- Travel time
- User preferences

## MVP Features

### Court Discovery
- GPS-based court search
- Nearest courts
- Distance calculation
- Google Maps integration

### Availability
- Available time slots
- Daily and weekly overview
- Quick availability check

### Comparison
- Price comparison
- Distance comparison
- Availability comparison

### Booking
- Direct booking links
- Deep linking to booking providers
- No booking process inside the app

### Favorites
- Save favorite clubs
- Quick access list
- Custom sorting
